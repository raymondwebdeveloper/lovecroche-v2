# Love Croché Elegant Website

Static HTML/Tailwind/JavaScript website, ready for VS Code and GitHub Pages.

## Add the scroll video

1. Rename your final generated video to `hero.mp4`.
2. Place it inside the `assets` folder.
3. The final path must be `assets/hero.mp4`.

If the video is missing, the mall exterior poster remains visible so the website still works.

## Preview locally

Use the VS Code **Live Server** extension, then open `index.html`.

## Upload to GitHub Pages

Upload the contents of this folder to the root of your GitHub repository. Then open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/root`, then save.

## Included CDN libraries

- Tailwind CSS
- Google Fonts
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Lucide icons
